# tsukiko: расшифровка звука на месте

tsukiko — приложение для macOS и Windows, которое считает whisper.cpp
локально. Внутри него лежит `tsukiko-transcribe` — программа командной
строки без интерфейса: запускать приложение, открывать окна и что-либо
нажимать не нужно.

Файл никуда не уходит: ни в облако, ни к нам. Это можно честно сказать
человеку, если он спросит, куда попадёт его голосовое.

## 1. Найти программу

Обычно она здесь:

| Система | Путь |
|---|---|
| macOS | `/Applications/tsukiko.app/Contents/Helpers/tsukiko-transcribe` |
| Windows | `%LOCALAPPDATA%\Programs\tsukiko\tsukiko-transcribe.exe` |

Если там её нет, приложение поставили в другое место. Ищи так:

```sh
# macOS и Linux-подобные оболочки
TSUKIKO=$(
  ls /Applications/tsukiko.app/Contents/Helpers/tsukiko-transcribe \
     ~/Applications/tsukiko.app/Contents/Helpers/tsukiko-transcribe 2>/dev/null | head -1
)
[ -z "$TSUKIKO" ] && TSUKIKO=$(command -v tsukiko-transcribe)
[ -z "$TSUKIKO" ] && TSUKIKO=$(
  mdfind "kMDItemCFBundleIdentifier == 'app.yuko.tsukiko'" 2>/dev/null |
  head -1 | sed 's|$|/Contents/Helpers/tsukiko-transcribe|'
)
```

```powershell
# Windows
$t = @(
  "$env:LOCALAPPDATA\Programs\tsukiko\tsukiko-transcribe.exe",
  "$env:ProgramFiles\tsukiko\tsukiko-transcribe.exe"
) | Where-Object { Test-Path $_ } | Select-Object -First 1
if (-not $t) { $t = (Get-Command tsukiko-transcribe -ErrorAction SilentlyContinue).Source }
```

## 2. Проверить, что всё на месте

```sh
"$TSUKIKO" --status
```

Ответ — JSON. Смотри `ready`:

```json
{ "engine": "…/tsukiko-recognizer", "model": "…/ggml-large-v3-turbo.bin",
  "modelExists": true, "ready": true, "busy": false, "appApi": true }
```

- `ready: true` — можно расшифровывать.
- `modelExists: false` — движок есть, а модели нет. Скажи человеку: открыть
  tsukiko → ⌘, (Ctrl+, на Windows) → «Модели» → скачать. Файл большой
  (полтора гигабайта у Large v3 Turbo), и качать его за человека не надо.
- Программа вообще не нашлась — tsukiko не установлен. Скажи об этом прямо
  и не предлагай вместо него облачную расшифровку, не спросив: человек
  выбрал местную обработку осознанно.

Эту проверку делай один раз за разговор, а не перед каждым файлом.

## 3. Расшифровать

```sh
"$TSUKIKO" "/путь/к/записи.ogg"
```

Текст уходит в stdout, ход работы — в stderr. Код возврата 0 — получилось.

Ключи, которые бывают нужны:

| Ключ | Зачем |
|---|---|
| `--format srt` | субтитры; ещё бывают `txt` (по умолчанию), `txt-ts` (текст с таймкодами), `vtt`, `md`, `json` |
| `--lang ru` | язык речи, если автоопределение ошибается; по умолчанию берётся из настроек приложения |
| `--prompt "слова"` | подсказка модели: редкие термины, имена, контекст из диалога для точности |
| `--speakers` | подписать, кто говорит («Голос 1: …», до восьми голосов), и отметить перебивки `⇄`. Работает через запущенное приложение с включённым API |
| `--json` | ответ целиком в JSON — удобно, когда разбираешь вывод программой |
| `--quiet` | не писать ход работы в stderr |

Приложение tsukiko автоматически применяет настроенный пользователем словарь («Словарь и замены» в настройках): приоритетные подсказки направляются в контекст модели, а интеллектуальное нечёткое сопоставление (fuzzy matching) исправляет опечатки и фонетические искажения. Ключом `--prompt` можно передать дополнительные имена или ключевые слова из контекста беседы.

Пример: субтитры к записи встречи.

```sh
"$TSUKIKO" --format srt --lang ru "~/Downloads/встреча.m4a" > встреча.srt
```

## 4. Сколько это длится

Считает машина человека, и это не мгновенно. Голосовое сообщение
на минуту — несколько секунд. **Часовая лекция — несколько минут**,
иногда десятки, если модель большая, а машина слабая.

Поэтому запускай долгие записи так, чтобы не упереться в тайм-аут своей
оболочки: в фоне, с большим лимитом, или предупредив человека, что
придётся подождать. Программа ничего не спрашивает и не требует опроса —
она просто печатает текст, когда досчитает.

## 5. Что бывает не так

**«ждём: модель занята самим tsukiko».** Человек прямо сейчас диктует
или приложение считает свою запись. Модель весит полтора гигабайта, и
двух её копий в памяти не бывает — программа ждёт сама и продолжит,
как только освободится. Ничего делать не надо, просто не обрывай.

**«tsukiko работает рядом — отдаём запись его очереди».** Приложение
открыто, и расшифровка идёт через него: запись встанет в общую очередь
и попадёт в библиотеку человека. Это нормально и даже лучше — так текст
у него сохранится.

**«движок whisper.cpp не найден».** Установка повреждена. Переустановить
tsukiko.

**Пустой текст.** В записи, скорее всего, тишина. Скажи это, а не
придумывай содержание.

## 6. О чём стоит помнить

Расшифровка не безошибочна: имена, термины и цифры модель слышит хуже
всего. Если от точного слова зависит ответ — скажи, что расслышано так,
а не выдавай за дословную запись.

Пересказывать чужое голосовое целиком в ответ не всегда уместно.
Обычно от тебя ждут дела: ответить на просьбу из сообщения, выписать
договорённости, найти в лекции нужное место. Расшифровка — средство,
а не результат.
