# Tsukiko · эскиз 02

Изолированный Flutter-стенд для сравнения нынешнего котика с параметрическим векторным эскизом. После обратной связи пользователя прежний дизайн котёнка с лапками, нагрудником, спиральным хвостом и знаком на лбу снят с показа. Сначала согласуется узнаваемая лунная база; солнечный и персональный варианты отложены.

В новой базе сохранены высокие неодинаковые уши, наклон головы и глаз, широкие щёчки, мягкий румянец, маленький рот, боковое тело с прижатым хвостом и растворение снизу. Перерисованы программные пути по предоставленному пользователем скриншоту. Это работа над сходством, а не утверждение независимого происхождения нового персонажа. Скриншот включён только для визуального сравнения; рабочие файлы маскота приложения не заменяются.

## Запуск

Из этой папки:

```sh
flutter pub get
flutter run -d chrome
```

Или локальная статическая версия:

```sh
flutter build web --no-web-resources-cdn --no-wasm-dry-run --output /tmp/tsukiko-mascot-lab-web
python3 -m http.server 4837 --bind 127.0.0.1 --directory /tmp/tsukiko-mascot-lab-web
```

Открыть http://127.0.0.1:4837. Остановка сервера — Ctrl+C. После локальной проверки выполнить `flutter clean` в этой папке. Временная веб-сборка хранится отдельно от репозитория.

## Проверка образа

Слева — предоставленный референс, справа — векторный кот. Движение изначально выключено, чтобы оценивать рисунок. Можно включить дыхание, моргание и локальное слежение за курсором, проверить состояния «Покой», «Слушает», «Думает», «Радуется», нажать на кота для краткого подмигивания. Доступны Tab и Enter/Space; учитываются reduced motion, TickerMode и жизненный цикл приложения.

Официальный `blobatar: 0.1.0` предоставляет выражения, интерполяцию поз, детерминированные движения и геометрию глаз. Слежение сделано на Flutter через MouseRegion без дополнительной зависимости. Базовые глаза увеличены и сделаны неровными в соответствии с нынешним персонажем. Это собственный Canvas-рендерер поверх публичного ядра пакета.

Микрофон не включается. Состояния демонстрационные; сохранение внешности, привязка к диктовке, персонализация и нативный HUD не подключены. Пропорции сначала требуют художественного согласования.

## Проверки

```sh
flutter analyze
flutter test
PREVIEW_DIR=/tmp/tsukiko-mascot-previews flutter test
```

Последняя команда сохраняет `reference-comparison.png`. Проверяются сохранение статуса при нажатии, компактная раскладка, клавиатура, reduced motion, слежение, пауза и отрисовка выражений. Тесты не заменяют визуальную оценку сходства.
