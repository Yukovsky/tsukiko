# Tsukiko · живой кот, эскиз 03

Изолированный Flutter-стенд: полный кот и компактная мордочка используют один профиль, одни эмоции и один рендерер. Рабочее приложение и его зависимости не изменены.

После проверки точного сходства в эскизе 02 геометрия переработана: сохранены неравные высокие уши, большие светлые глаза, мягкие щёчки с румянцем и небольшой боковой корпус. Пути головы, ушей и корпуса построены отдельно, чтобы персонаж мог двигаться целиком. Исходный скриншот остаётся сворачиваемым ориентиром и не участвует в отрисовке нового кота.

## Попробовать

- Переключать восемь состояний. Движение включено сразу; кнопка «Остановить» позволяет проверить выразительность неподвижной позы.
- «Слушает»: поднятая выровненная голова, развёрнутые уши, вытянутый корпус и приподнятый хвост. Регулятор демо-голоса меняет движение ушей, хвоста и силу свечения; микрофон не включается.
- «Думает»: наклон головы, неодинаковая постановка ушей, неспешный хвост и движущиеся глаза Blobatar.
- «Радуется»: улыбка глазами, поднятые уши, лёгкое движение корпуса и более живой хвост.
- «Грустит» и «Сонный»: опускаются голова, уши и корпус; настроение видно при остановленном движении.
- Наведение направляет глаза и немного поворачивает голову. Нажатие вызывает короткий жест с подмигиванием, движением ушей, корпуса и хвоста. Работают Tab и Enter/Space.
- «Из аватара» и строка внешности меняют палитру и ограниченные кошачьи пропорции обоих форматов. Исходный Blobatar показан рядом.

Полный персонаж подходит для свободной области главного окна, мордочка — для компактной панели. Это два представления одной геометрии, а не два отдельных комплекта анимаций. Пример небольшой панели показан в стенде; нативный HUD приложения пока не подключён.

## Что реализовано

Официальный `blobatar: 0.1.0`: seed/traits, палитра, Expression/Pose, интерполяция выражений, моргание, дыхание и фоновые взгляды. Поверх него — небольшой числовой `CatRig` с позой головы, поворотами двух ушей, наклоном/растяжением корпуса и положением хвоста. При смене настроения интерполируются лицо и вся поза, включая прерывание перехода. Поглаживание складывается с текущим состоянием, не убирая запись.

Слежение — MouseRegion и приближение с учётом времени кадра, без дополнительной библиотеки. Каждый кот перерисовывается внутри RepaintBoundary. Reduced motion оставляет полную статичную позу; TickerMode, пауза и жизненный цикл останавливают непрерывные кадры.

Состояния выбираются вручную, внешний вид не сохраняется, голос демонстрационный. В этой версии не выполнялись замеры CPU/FPS и проверка нативного macOS/Windows HUD. Солнечный пресет отложен до выбора базового образа и формата. Прежде чем считать рисунок финальным брендовым ассетом, требуется отдельная художественная оценка его самостоятельности.

## Запуск

Из этой папки:

```sh
flutter pub get
flutter run -d chrome
```

Либо статическая версия, которая используется для локального просмотра:

```sh
flutter build web --no-web-resources-cdn --no-wasm-dry-run --output /tmp/tsukiko-mascot-lab-web
python3 -m http.server 4837 --bind 127.0.0.1 --directory /tmp/tsukiko-mascot-lab-web
```

Открыть http://127.0.0.1:4837. Остановка сервера — Ctrl+C. После проверки выполнить `flutter clean` здесь; временную веб-сборку можно удалить отдельно.

## Проверки и изображения

```sh
flutter analyze
flutter test
PREVIEW_DIR=/tmp/tsukiko-mascot-previews MOTION_PREVIEW=1 flutter test
```

Проверяются полный/компактный форматы, изменения позы слушания, состояние записи во время реакции, прерывание перехода без скачка, персонализация, раскладка при ширине 390 px, клавиатура, reduced motion, слежение, пауза и отрисовка выражений при крайних пропорциях.

Последняя команда экспортирует снимок стенда и 72 PNG-кадра от того же CatPainter. Из них получен `previews/living-states.gif` (15 кадров/с). Это демонстрация покоя, слушания, размышления и радости в двух форматах; живой стенд показывает реакции и переходы интерактивно. Предыдущий `reference-comparison.png` сохраняет результат эскиза 02.
