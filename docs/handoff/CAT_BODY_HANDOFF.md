# Handoff: тело котика по нарисованным листам

Ветка: `claude/confident-mccarthy-nx0b52`. Код кота: `lib/design/cat/`.
Сравнения «лист / код» в текущем состоянии: `docs/handoff/cat-*-sheet-vs-code.png`
(слева твой лист, справа рендер кода).

## Цель

Тело кота из кода, максимально похожее на листы tsukiko, lumi и yuko (6 поз:
сидит, радуется, грустит лёжа, лежит настороже, спит клубком, стоит). Плюс:
- плавные переходы между позами;
- анимация;
- работа генератора: наряды, узоры, хвосты, без «каши».

Голова и мордочка остаются генерируемыми (генератор, эмоции, моргание).

## Что пробовали и почему не подошло (подход 1, отброшен)

Примерно 19 раундов я собирал тело из параметрических частей: туловище из
8 точек Catmull-Rom, бёдра-овалы, лапы-капсулы, хвост сначала углами, потом
5 точками. Сверху шли пружины между позами. Оценки давал независимый
проверяльщик (Opus): итог «очень похоже», 8–8.5/10, «не отличить» не
достигли. Тебе результат не понравился: силуэт не сужается кверху, лапы не
под наклоном, пушок у шеи не того размера, хвост не той формы. Конструктор
из примитивов рисунок не повторяет, а подгонка чисел упирается в потолок.

Отдельно не сработали (проверяльщик оценил хуже, всё откачено):
- мех штрихами внутри контура — выглядит как штриховка;
- размытая линия — грязный ореол;
- частые пучки меха по силуэту — спина как «гусеница»;
- тени-градиенты (аэрограф) — «пластик»;
- мазки кистью — «замшевые» разводы;
- переменная толщина линии — дорого по кадру, эффекта почти нет.

Сработали: светлее шерсть, мягкий тон по свету, нарисованные пятна тени с
мягким краем. Но для нового подхода это уже не так важно.

Вся история подхода 1 лежит в коммитах до `0aa5c15` включительно.

## Новый подход (подход 2): трассировка твоих листов в векторные данные

Тело больше не собирается из примитивов, а **трассируется из твоих рисунков**
и хранится в коде как контуры:

1. `tool/cat_trace/extract.py` режет лист на 6 ячеек и выделяет силуэт кота.
2. `tool/cat_trace/eyes.py` находит глаза на каждом рисунке. По ним ставится
   сгенерированная голова: середина глаз, масштаб по расстоянию между
   глазами, наклон по линии глаз (наклон учитывается только для сна).
   Результат пишется в `eyes.json`.
3. `tool/cat_trace/trace.py` делает основную работу:
   - вырезает нарисованную голову (по контуру сгенерированной головы × `HK`,
     плюс убирает тонкие остатки ушей) и оставляет «пробку» шерсти под
     головой;
   - делит тело по тону на слои `base`, `shade`, `deep` (полосы, тёмные
     кончики), `light` (пушок) и `ink` (все линии как залитые фигуры, с
     ручной толщиной из рисунка);
   - помечает хвост: кончик ищется автоматически, вес от корня к кончику
     нужен для виляния;
   - пересэмплирует контур тела в 200 точек для морфинга между позами.
4. `tool/cat_trace/emit.py` пишет `lib/design/cat/figure_data.dart`
   (base64 int16, около 125 КБ).
5. `lib/design/cat/figure.dart` (переписан с нуля):
   - перекрашивает слои под окрас кота;
   - машет хвостом (поворот точек с весом хвоста), дышит, подпрыгивает,
     покачивается, дрожит;
   - между позами морфит контур, детали старой позы гаснут, новой —
     проявляются, голова плавно переезжает;
   - рисует поднятые лапки (у подбородка, сложенные, на щеках, машет);
   - рисует значки (сердечки, z, ?, многоточие, капля, 💢);
   - рисует наряды (ошейник, шарфик, ленточка на хвосте);
   - добавляет метки, которых нет на листах: пятно, звёзды, тёмный или
     светлый кончик хвоста.
   - Выбор листа: полоски → lumi, пушистый хвост → yuko, остальные →
     tsukiko. Настроение → одна из 6 поз (`BodyPose.forMood`).

Пересборка после правки рисунков или трассировщика (нужны `opencv-python`
и `numpy`):

```bash
flutter test tool/cat_trace/headgeo_test.dart
```

```bash
cd tool/cat_trace && python3 eyes.py && python3 trace.py && python3 emit.py ../../lib/design/cat/figure_data.dart
```

`headgeo_test` пишет `tool/cat_trace/head.json` — контур сгенерированной
головы. Его нужно перезапускать после любой правки формы головы в
`silhouette.dart`. Исходные листы лежат в `design/cat_sheets/`.

Посмотреть результат листами 3×2, как твои:

```bash
OUT=/tmp flutter test tool/cat_trace/refsheet_test.dart
```

## На каком шаге остановился

Тело по подходу 2 работает, тела и хвосты совпадают с листами (см.
`docs/handoff/*.png`). Разница сейчас **в голове**: сгенерированная голова
шире, квадратнее и с плоским низом, а нарисованная круглее и сливается с
пушком на груди.

Последний шаг (сделан, но не проверен глазами и не отдан проверяльщику):
1. Форма головы `mochi` и ушей `moon` / `tuft` в `silhouette.dart` подогнана
   по замерам нарисованной головы (в радиусах головы от середины глаз):
   - лоб примерно 0.98;
   - щёки примерно 1.15 сразу под глазами;
   - ниже щёки остаются полными;
   - уши уже.
2. Линия под подбородком гаснет (`chinOpen` в `_paintHead` / `_ink`), чтобы
   голова переходила в пушок без линии челюсти.

## Что делать дальше (по порядку)

1. Отрендерить листы и сравнить голову с рисунком (замеры профиля — в
   истории сессии; ориентир — числа выше). Если голова всё ещё «коробкой»,
   есть вариант сильнее: трассировать контур нарисованной головы тем же
   способом, что и тело, и сделать его формой `mochi` по умолчанию.
2. Масштаб головы: `_headScale = 1.1` в `figure.dart` и `HK = 1.15` в
   `trace.py`. Голова на рендере чуть крупнее нарисованной. Если уменьшать,
   то оба числа вместе, и пересобрать данные.
3. Проверить анимацию переходов (покадровая раскадровка:
   `tool/catlab/anim_test.dart` + `contact.py` в истории сессии) и отдать
   независимому проверяльщику.
4. Лаборатория `prototypes/mascot_lab` ещё на старом (подход 1) коде. Чтобы
   синхронизировать, скопировать туда `cat.dart`, `figure.dart`,
   `figure_data.dart`, `genome.dart` и `silhouette.dart` и поправить
   `test/art_sheet.dart` (`FigureState.at`).
5. После финала:
   - перерисовать брендовые картинки:
     `BRAND_ART=1 flutter test test/design/cat/brand_art_test.dart`
     (на Linux нужна временная заглушка Os);
   - на маке пересобрать DMG и баннеры:
     `tool/dmg-background.py` и `tool/installer-images.py`.
